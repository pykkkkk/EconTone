# econtone-score

**只评分，不编辑。** 对英文学术文本给出四项评分与**编辑幅度**，后者决定下游允许改到什么程度。

[English](README.md) | **中文**

## 输入与输出

| 输入 | 输出 |
|---|---|
| 英文草稿（摘要、正文、回复信均可） | 四项明细（术语 40 / 主张 40 / 痕迹 10 / 节奏 10）、总分、编辑幅度 |

四项分别为：`P1` 术语与语域、`P2` 主张与结构、`T1` AI 痕迹风险、`R1` 韵律。

```bash
python scripts/score.py draft.md --profile abstract
```

`--profile` 取 `abstract`、`intro` 或 `body`，决定韵律与结构的参照带。

## 编辑幅度

幅度由总分映射得出：50 分以上走余弦四分之一波衰减，从 100% 降至 0。幅度不是建议，而是**约束**——它定义
下游可行动作集的边界。

## 不做什么

- 不改写任何句子；
- 不给出修改建议；
- 不判断学术价值，只判断表述是否符合该文体。

## 限制

`P2` 依赖正则识别研究设计，`instrumental variable` 等写法未收录时会误报"未说明设计"；`significant`
出现在非统计语境时可能被计为效应主张。标注 `[n/a]` 的项不计入总分。
