# References

Every work this project cites, in one place, APA 7th edition. Each skill's own README also lists the works it
uses, with a note on what that skill does and does not take from them; this file is the complete list.

**What the citations mean.** A work is listed because something in the repository depends on it — a method
whose definition we implemented, a guide whose advice we paraphrased, a catalogue we checked. The **numbers**
in this project — bands, thresholds, marker levels, score deductions, the composition of `risk_index` — are its
own calibration and are not reported in any of these works.

DOIs are given where they were verified. Where none appears, the work predates widespread DOI assignment or is
an unpublished manuscript; the absence is not an omission.
