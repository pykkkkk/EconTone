# econtone-polish

**句内改写。** 处理术语、语域、主张强度与语法，不改动句子边界，不替代作者判断。

[English](README.md) | **中文**

## 第 0 步：机械与语法修正（无条件）

拼写、英美一致性、语法错误是**错误而非取舍**，先修正，不进入均衡，不能因为提高风险指标或降低节奏分而被否决。

```bash
python scripts/mechanical_check.py draft.md
```

脚本覆盖：英美拼写混用、拼写错误、重复词、标点前空格、`a/an` 一致、LaTeX 残留。

**语法不在脚本范围内。** 一致性、时态、冠词、介词搭配由模型判断，但同样必须修正——脚本看不见的错误仍是错误。

## 输入与输出

| 输入 | 输出 |
|---|---|
| 英文文本 + 拟表达的主张 | 修改稿、变更清单、`[MAGNITUDE?]` 标记 |

## 核心规则

- **术语不可交易**：规范术语不得为更短的近义词让路；
- **主张强度匹配设计**：相关性设计不得写成因果，缺量级时标注 `[MAGNITUDE?]`，不得代为补全；
- **句界不属于本 skill**：拆分与合并由 `econtone-prosody` 负责。

## 限制

规则来源于公开写作指南，反映的是**已发表论文的惯例**，不是期刊的成文规定。语域判断依赖模型，不同模型可能给出
不同结论；术语命中可复现，语域判断不可完全复现。
