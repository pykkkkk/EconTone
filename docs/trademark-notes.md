**Status: preliminary screen, not a clearance search. Not legal advice.**
Screened 2026-11-07 by web search only; no trademark database was queried directly.

## Why this is not clearance

1. Web search does not index trademark registers. The relevant registers are USPTO (TESS / Trademark Search),
   EUIPO eSearch plus, WIPO Global Brand Database, and — if the mark will be used in China — CNIPA.
2. The classes that matter for a writing tool are **Class 9** (software), **Class 41** (education, editorial
   services) and **Class 16** (printed matter). Printer consumables sit in a different class, which reduces
   but does not remove the risk: registers examine similarity of marks as well as similarity of goods, and
   an examiner may still cite a close mark in an adjacent class.
3. A device mark helps. The registration would cover the **crescent arc + disc + gold line** together with the
   word: even if the word alone is crowded, the combined mark is easier to distinguish.

## Recommendation before any commercial use

- Commission a professional search covering at least CN, US, EU and WO, in classes 9, 16 and 41.
- File for the **combined mark** (word + device), not the word alone.
- Until then: use the name, keep the logo, do not imply registration, and do not use `™` or `®` in the
  repository or the docs.

## In this repository

The name is used descriptively for an open-source skill pack. No registration is claimed anywhere; the
licence (MIT) covers the code and text, not the name or the mark.
