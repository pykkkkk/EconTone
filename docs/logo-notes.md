# The mark: how it was made, and what its IP status is

The mark in `logo/brand/` — a black crescent arc, a black disc, a gold cycle line, and the wordmark whose
`Tone` is slate navy — was drawn with the **`logo-design`** skill (the public
[`kaankiziltug/logo-design-skill`](https://github.com/kaankiziltug/logo-design-skill), MIT), used through its
Design workflow: brief, category research, three concepts, SVG construction, audit, then a delivery kit.

## What the skill provided, and what it did not

| The skill provided | The skill did not provide |
|---|---|
| the process (discovery brief → conventions of the category → 8–12 one-liners → three concepts → build → audit → checkpoint) | the mark itself |
| `svg_audit.py`, which scored the twelve masters: symbols 100/100, wordmarks 99, horizontal lockups 98, stacked 99, no warnings | any path, curve, or composition from its reference library |
| a 1,432-logotype library, searched only to learn what the category looks like so the result could avoid it | a licence to reuse those logotypes |

The library is a **study corpus**. Every logo in it is a registered trademark of its owner. Nothing from it was
traced, measured, or adapted; it was searched for the opposite reason — to find out which shapes the category
already owns (arrows, shields, globes, hexagons) and not draw them.

## What is not claimed

- No trademark registration, no `™`, no `®`, and no endorsement by the author of the `logo-design` skill.
- No exclusivity: the mark is unregistered, and an unregistered mark can coexist with a similar one elsewhere.
- No claim that the mark is unique. A preliminary screen found a toner-cartridge brand using the same word in a
  different class; it is recorded in [`trademark-notes.md`](trademark-notes.md).

## Before commercial use

1. Record or replace the wordmark typeface (see the open item above).
2. Run a professional trademark search in classes 9, 16 and 41 (link in the trademark notes).
3. Keep the full delivery package — usage rules, build scripts, the arc-disc option studies — internal. Only
   the four files in `logo/brand/` are published.
